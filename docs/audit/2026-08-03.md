# Audit — 2026-08-03 (v2.6.11 tree, scoping the 2.6.12 repair sweep)

**Scope:** all 34 math modules in `src/` (16,908 lines) at released tag `2.6.11`, plus the four
test suites. `lib/` (vendored stdlib) and `dist/` (generated) were explicitly out of scope.

**Method:** 8 parallel audit dimensions — numerical correctness (split three ways: foundation/
transform, geometry/calculus/numerics, symbolic/Lie/diffgeo), memory safety, performance, API &
error-handling consistency, test coverage, dead code & docs. Every candidate finding was then
handed to an independent adversarial verifier instructed to **refute** it by reading the real
code and, where possible, compiling and running a probe against the actual modules on cyrius
6.5.6. Findings that could not be reproduced were dropped.

**Result: 70 findings survived verification; 7 were refuted.** By severity: **2 critical, 23
high, 23 medium, 22 low**, across **64 distinct sites in 27 files**. By category: correctness 36,
memory-safety 11, docs 10, performance 7, test-coverage 4, api-consistency 2.

This supersedes nothing — it is a new dated artifact. It does, however, **correct the record** of
two earlier reports: `2026-05-29-cga-arc-closeout.md` and `2026-05-30.md` both concluded "posture
solid". Both were scoped to the functions their arc had just added and neither reached the modules
that no test suite includes. That scoping limit is the single highest-leverage finding here.

---

## 1. The systemic defect: hand-encoded IEEE-754 constants

Seven separate hex constant tables in `src/` do not encode the values their own adjacent comments
state. This is one mechanical mistake repeated, not seven independent errors — and because the
comments are correct, the intent is unambiguous in every case.

Four are published numerical-method tableaux, each falsified by its own invariant. These were
**re-confirmed independently of the audit agents** by decoding the shipped literals directly:

| Table | Site | Invariant | Shipped | Required |
|---|---|---|---|---|
| Dormand-Prince RK4(5) | `ode.cyr:55-88` | Σb = 1 | **0.635581152612211** | 1.0 |
| Gauss-Legendre 5-point | `calc.cyr:96-107` | Σw = 2 | **2.000492320194892** | 2.0 |
| BDF-4 | `ode.cyr:108-110` | Σα = 1 | **1.01** | 1.0 |
| Yoshida-4 symplectic | `ode.cyr:130-136` | 2w₁+w₀ = 1 | **1.4737899450113117** | 1.0 |

DOPRI45 additionally fails the stage-consistency condition `Σⱼ a_ij = c_i` on rows 3, 4, 5 and 6
(row 3 sums to 0.25 against c₃ = 0.3; row 4 to 0.6889 against c₄ = 0.8). With 23 of 30 constants
wrong it is **not a consistent integrator at any order** — it does not merely lose accuracy, it
converges to the wrong solution. `joshua` (simulation) consumes DOPRI45, BDF and the symplectic
integrators directly.

The remaining three: `color.cyr:9-10` sRGB piecewise breakpoints (0.03275 shipped against the
IEC 61966-2-1 value 0.04045), `color.cyr:188-191` four of five spherical-harmonic normalisations,
and `noise_simplex.cyr:16` `_SIMPLEX_G2` (encodes √3 as 1.73158 rather than 1.73205, so the
skew/unskew pair is not an exact inverse).

**Recommendation:** re-derive all seven from exact rationals, and add a harness that decodes every
hex f64 literal in `src/` and asserts it against the value in its own comment. The class is
mechanical; the guard should be too.

## 2. The root cause: untested surface

`cyrius coverage` reports **297/587 functions referenced (50%)** against CLAUDE.md's 80% target.
Eight modules are included by **no** test suite — so they are not merely unasserted, they are not
compiled at all by `cyrius test`:

| Module | Lines | Fns | Module | Lines | Fns |
|---|---|---|---|---|---|
| `linalg_precision.cyr` | 1,124 | 12 | `lie_ext.cyr` | 523 | 37 |
| `symbolic_ext.cyr` | 974 | 40 | `noise_simplex.cyr` | 343 | 8 |
| `calc_ext.cyr` | 799 | 18 | `einsum.cyr` | 330 | 8 |
| `num_ext.cyr` | 769 | 20 | `mat3.cyr` | 206 | 18 |

**5,068 lines — 30% of `src/` — and 104 public functions, all shipped in `dist/hisab.cyr` to
8 consumers.** The correlation with the defect map is the point: **35 of 65 source findings sit in
modules at ≤30% function coverage.** The bugs are not randomly distributed; they are where the
tests are not.

Two further coverage defects are worse than absence, because they give false assurance:
`ode_dopri45`'s only assertions are `1 < y < 2` for a quantity whose exact value is 1.10517 — a
non-consistent integrator passes — and the `gauss5` assertions round to the nearest integer,
tolerating ±0.5 absolute and hiding a 246 ppm error floor.

## 3. Cross-module private coupling

The README documents an à-la-carte `modules = ["src/vec3.cyr", …]` consumption path. Five module
pairs reach across boundaries into another module's `_`-prefixed private symbols:
`noise_simplex` and `calc_ext` → `calc`'s `_perm`/`_perm_init`/`_noise_fade`; `lie_ext` →
`lie`'s `_su2_*`; `num_ext` → `num`'s `_num_mulmod`/`_num_is_pow2`; `symbolic_ext` →
`symbolic`'s `_sym_is_zero`.

The full bundle is unaffected — the dependency graph is a **DAG** and the `[lib]` order is a valid
topological sort (both verified) — but a consumer selecting files individually gets link errors
with no manifest to consult.

## 5. What is genuinely clean

Recorded so the next audit does not re-plough it. Verified correct by tracing and, in most cases,
by execution:

- **All of `diffgeo.cyr`** — Christoffel index ordering and symmetry, Riemann contraction indices,
  Ricci/Einstein/Weyl, sectional curvature, the geodesic-deviation sign convention, the geodesic
  RK4 stages, parallel transport, Killing residual, wedge/Hodge index maps. (One docs-only defect
  on `hodge_star_2form_4d`'s `sign` parameter.)
- **`symbolic.cyr`'s** differentiation (product/quotient/chain), simplification and evaluation;
  `symbolic_ext.cyr`'s integration and pattern-matching engine.
- **`mat4`/`mat3` inverse and determinant** — round-trip error < 1e-9, determinants match numpy,
  column-major cofactor sign layout traced entry-by-entry.
- **`hquat_slerp`** — shortest-path negation correct, and the `d > threshold` branch makes the
  `inv_sin` division provably safe.
- **`geo.cyr`'s** Möller-Trumbore, slab tests and Ericson Voronoi-region closest-point;
  `geo_advanced.cyr`'s CGA blade algebra, BVH, GJK/EPA.
- **`num.cyr`/`num_ext.cyr`** gcd, totient, Möbius, CRT, tridiagonal solve, FFT/IFFT, and Kahan/
  Neumaier compensated summation.
- **`spatial.cyr`'s** quadtree/octree/spatial-hash query logic (the k-d *partition strategy* is a
  separate finding; the query code is correct).
- **`solve_gmres`**, the CSR sparse routines, `cqr_decompose`, `cmat_inverse`'s algorithm, and
  `so3_exp`/`so3_log` including the θ = π eigenvector branch.
- The SIMD n=2 + scalar-tail decomposition in `hvec3_*`/`m3_mul` — index arithmetic traced, no
  over-read past the 24-byte allocation.
- Every allocation guard hisab owns (`tensor_new`, `cmat_new`, `christoffel`/`riemann` dim cap,
  `mat_new_guarded`) behaves as documented.
