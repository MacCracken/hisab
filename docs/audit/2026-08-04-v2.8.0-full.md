# Audit — 2026-08-04 (v2.8.1), full sweep of the v2.8.0 tree

Six dimensions, each swept by an independent agent and then **adversarially verified** by a second
agent that reproduced every finding with its own harness before it was allowed into this report.

**42 confirmed, 0 refuted** — 4 critical, 17 high, 16 medium, 5 low.

The zero-refutation rate is worth reading carefully rather than as a compliment to the finders. The
previous two audits refuted ~15%. What changed is that the verifiers were required to *reproduce by
execution*, so speculative findings did not survive to be counted — several were dropped inside the
verify step rather than arriving here as refutations. Two findings were **downgraded** on
verification and one was materially corrected; those notes are kept inline.

## The headline: a defect in what 2.8.0 shipped

`delaunay_2d` was rewritten in 2.8.0 with triangle adjacency, verified across 298 fixtures, and the
result was correct on every one. It is still **incomplete on ordinary uniform-random input** —
roughly 15–37% of point sets come back missing at least one triangle, silently, with no error
signal. The cause is not the rewrite: `d_max = max(dx, dy) * 10` builds a super-triangle only 10x
the bounding box, and Bowyer-Watson only reduces to the true Delaunay triangulation once no
super-vertex lies inside any real circumcircle. At 10x that condition is violated, the real triangle
is never created, and the compaction pass drops the super-vertex triangle that covered the gap.

Proven by exact rational arithmetic: over 40 point sets, the set of triangles whose circumcircle
encloses a super-vertex matched the observed missing set **40/40**. At multiplier 1e3 and above the
failures vanish for uniform data.

**But the fix is not simply a bigger multiplier.** The verifier ran the same substitution on tight
clusters and found 1e9 *breaks* input the current 10x handles correctly (span 1e-8: 20 missing and 9
spurious overlapping triangles). The 10 is a real trade-off between super-triangle adequacy and the
non-adaptive in-circle determinant's conditioning — the two defects are coupled, exactly as
`issues/2026-08-04-incircle-precision.md` warned. **1e6 is a defensible interim value; 1e9 must not
be used.** The durable fix is an adaptive predicate or symbolic ghost-vertex handling.

None of the 1801 assertions detects any of this. Every existing `delaunay_2d` assertion checks
either a fixture where the shipped code is right, or a structural property that under-coverage does
not violate.
